# FANSITE

FANSITE is a small, educational web project intended to teach the fundamentals of modern web development using plain HTML and CSS. It is designed as a hands-on repository for learners who want a practical playground to practice layout, styling, responsive design and semantic markup.

## Project goals
- Provide a compact, easy-to-understand codebase for beginners.
- Demonstrate common HTML structures (header, nav, main, article, aside, footer).
- Show CSS layout patterns (normal flow, Flexbox, CSS Grid).
- Teach responsive techniques (media queries, fluid units).
- Encourage progressive enhancement and accessible markup.

## Who is this for
- Absolute beginners learning HTML & CSS.
- Students who want structured exercises to practice common layout tasks.
- Instructors who need a small example repository to demonstrate concepts.

## Prerequisites
- A basic text editor (VS Code, Sublime, Notepad++).
- A modern web browser (Chrome, Firefox, Edge, Safari).
- Optional: Live Server extension or a simple local HTTP server for refresh-on-save.

## Repository structure (example)
- index.html — main page with sample content and semantic structure.
- css/
  - styles.css — main stylesheet demonstrating layout and components.
- assets/
  - images/ — sample images used in the site.
- README.md — this document.

## How to open and test locally
1. Clone the repository or download the project folder.
2. Open `index.html` directly in your browser, or run a local server:
   - VS Code: use Live Server extension.
   - Python 3: run `python -m http.server` in the project folder and open http://localhost:8000.
3. Inspect and modify HTML/CSS files and refresh the page to see changes.

## Learning objectives & highlights
- Semantic HTML: Use tags that describe content role (section, article, nav).
- CSS basics: selectors, specificity, box model, margins, padding, borders.
- Layout techniques:
  - Vertical and horizontal alignment with Flexbox.
  - Two-dimensional layouts with CSS Grid.
  - Creating headers, navigation bars, cards and footers.
- Responsive design: fluid layouts, breakpoints, and accessibility-first thinking.
- Images and media: responsive images, aspect ratios, and optimization tips.
- Small accessibility notes: meaningful alt text, proper heading order, focus styles.

## Suggested exercises
- Recreate the header and navigation from scratch using semantic HTML.
- Build a responsive grid of "fan cards" that stacks on small screens.
- Implement a simple CSS-only dropdown menu.
- Add a contact form and style inputs with focus/active states.
- Convert a fixed-width layout to a fully responsive one using Grid and Flexbox.

## Tips for instructors / learners
- Start by reading the HTML and identify main sections before touching CSS.
- Make small incremental changes and use the browser DevTools to inspect styles.
- Commit changes frequently and use branches for experiments.
- Compare different layout approaches (float, Flexbox, Grid) to understand trade-offs.
